## Gotchas / things to remember

- **PARALLELLE ØKTER I SAMME MAPPE ER FARLIG.** Denne økta og rydde-økta kjørte
  samtidig; den andre økta resatte en branch denne økta nettopp hadde committet
  på — committen ble foreldreløs og måtte reddes via `git reflog` + cherry-pick.
  Regel (lagret i Claude-minnet også): sjekk `git branch --show-current` rett før
  hver commit, og gjør branch-arbeid i et midlertidig `git worktree` under
  scratchpaden. Alt etter kollisjonen ble gjort i worktrees — null problemer.
- `git worktree remove` feiler på Windows hvis worktreet har node_modules
  (lange stier). Løsning: `cmd /c rmdir /s /q "\\?\<sti>"`.
- Meta-testen (#92) gjør deler av `/check-rls` overflødig ved PR-tid — men
  `/check-rls` er fortsatt nyttig interaktivt mot live DB.
- ESLint-blokkene i #93: senere config-blokker OVERSKRIVER `no-restricted-syntax`
  for filer de matcher (de merges ikke) — derfor gjentar unntaks-blokken
  sql.raw-selektoren. Ikke «rydd opp» dette uten å forstå det.
