## Gotchas / things to remember

- **Dev-server-porten var «Fast 4G»-throttla i DevTools** → LCP 2.98 s. Ikkje koden. Slå av throttling før du dømmer ytelse. LCP er uansett ein nettside-metrikk; appen er native.
- **Test knip på web:** Chrome device-modus, hald **Shift + dra**.
- **Hooken blokkerer alt som inneheld «push» + «main» i same kommando** — også `gh pr create --base main` når det står i same shell-linje som ein push. Køyr push og `gh pr create` som separate kommandoar.
- **Squash-merga branchar ser «ikkje merga» ut for `git branch --merged` og `git cherry`.** Sjekk PR-status (`gh pr list --state merged`) før du slettar — det var slik vi visste at dei sju var trygge.
- **`expo install`, ikkje `pnpm add`**, for Expo-pakkar — pinnar rett SDK-versjon.
- **Fleire agentar i same mappe:** Codex committa på `design/feed-polish` medan Claude jobba. Claude brukte eit worktree for backend-arbeidet av den grunn. Sjekk `git branch --show-current` før kvar commit.
- **`git cherry` gav «+» på alt** fordi squash endrar patch-id. Bruk PR-status eller `git cat-file -e origin/main:<fil>` for å sjå om innhald er inne.
- API-et køyrde frå Claude si økt (`pnpm dev`, port 3000) på slutten — den døyr med økta. Start sjølv: `pnpm --filter @knuteloop/api dev`.
