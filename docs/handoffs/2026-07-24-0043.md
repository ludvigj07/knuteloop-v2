## Gotchas / things to remember

- **Stacked-PR-merging:** GitHub LUKKER (ikke retargeter) barne-PR-er når base-branchen slettes, og lukkede kan ikke gjenåpnes → retarget barna til main FØR forelderen merges. Squash bryter slektskap → barnas branches blir CONFLICTING og CI kjører ikke (ingen merge-ref); fiks = merge origin/HEAD inn, løs med `--ours`, push. Notert i memory (gh-cli).
- **ALDRI `git add -A` under konfliktløsing** — de utrackede notatfilene (.agents/ osv.) ble med i en mellomcommit (fjernet umiddelbart, nådde aldri main).
- pre-bash-hooken blokkerer kommandoer med «main» → bruk `origin/HEAD` som ref.
- rls-meta-testens pinsTenant krever `school_id =` OG `current_setting('app.school_id'` i policy-teksten (deparsert form) — en ny policy med annen form vil (riktig) flagges; utvid bevisst hvis legitimt.
- Dev-identiteten ligger nå i localStorage (kun web/dev) — «Bytt bruker (dev)» én gang per 8t-token.
- Feed-cursoren er nå `sharedAt`, ikke `createdAt` (opak for klienten).
