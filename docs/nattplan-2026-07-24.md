## Protokoll per PR

1. `git fetch origin` + branch fra `origin/HEAD` (ALDRI ordet «main» i kommandoer — hook).
2. Bygg (selv / Opus-agent / Codex i worktree).
3. `pnpm typecheck && pnpm lint && pnpm test` (Docker må kjøre for API-testene).
4. Backend-diff → `/backend-review`. Alle diffs → minst én uavhengig review-agent
   promptet til å REFUTERE (adversarial). Funn verifiseres og fikses før videre.
5. `git add <eksplisitte filer>` (ALDRI `-A`), commit, `git push origin <branch>`,
   `gh pr create` (SEPARAT kommando fra push), grønn CI (`gh pr checks --watch`),
   `gh pr merge --squash --delete-branch`.
6. Neste oppgave. **Kvotevern:** nærmer Claude-kvoten seg taket → gjør ferdig
   påbegynt PR + skriv morgenrapporten i stedet for å starte nytt.
